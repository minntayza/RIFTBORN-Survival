# Enemy concept artwork

Original designs generated with the built-in ImageGen tool for the Field Guide, matching the game's outlined cartoon palette. The zombie sheet contains nine organic enemy redesigns; the robot sheet contains seven robot concepts. They are concept illustrations only, not gameplay sprite replacements.

- `zombie-redesigns.png`: from `exec-1afc5cec-b2ea-45b1-ac45-78ec428a3bfe.png`; prompted as a 3x3 cartoon lineup of Wanderer, Runner, Spitter, Armoured, Brute, Elite, Fallen Rifleman, Horde Commander, and Zombie General, each with distinct anatomy, outfit, and equipment. No Butcher, Pike Guard, or Siege Gunner.
- `robot-designs.png`: from `exec-81ce9932-7818-4417-93f0-65e847035b27.png`; prompted as seven chunky dark-outlined robot designs: Scrap Walker, Scout Bot, Pulse Shooter, Shield Unit, Crusher, Command Unit, and Factory Sentinel. Slate metal, rust-orange accents, restrained cyan lights.

Originals remain in the session's Codex generated-images directory. The guide uses clipped SVG image regions to show individual illustrations while keeping names and descriptions as readable HTML.
