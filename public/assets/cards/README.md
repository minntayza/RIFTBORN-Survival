# Upgrade explanations

`upgrade-explanations.png` is an original static illustration atlas generated with the built-in ImageGen tool from the approved four-card concept sheet. The 2x2 panels are Piercing Shots, Wider Slash, More Health, and Regeneration. The prompt required no hero, hands, guns, swords, labels, or UI text: the selected hero and equipped weapon are composited dynamically by `src/upgrade-ui.ts`. Art uses chunky cartoon outlines, slate ground, readable zombies, bullet trails, a broad crescent, an extended health bar, and green recovery marks. No animation.

Original: `exec-eea0abcf-e396-4f7a-a7dc-cfe3ecf981be.png` in the session's Codex generated-images directory. The original is preserved.
